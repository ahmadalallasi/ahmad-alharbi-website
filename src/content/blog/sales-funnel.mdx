## ما هو Sales Funnel؟

مسار يمر به العميل من لحظة اكتشافه لك حتى الشراء. مهمتك تحسين كل مرحلة.

## المراحل الأربع

### 1. الوعي
العميل لا يعرفك. الأدوات: محتوى سوشيال + إعلانات توعوية + SEO.

### 2. الاهتمام
العميل يريد معرفة المزيد. الأدوات: فيديوهات + شهادات عملاء + مقالات.

### 3. القرار
العميل يقارن. الأدوات: عرض سعر واضح + ضمان + رد سريع.

### 4. الشراء
العميل جاهز. الأدوات: نموذج بسيط + خيارات دفع + تأكيد فوري.

## Funnel بميزانية 500 ر.س شهرياً

```
محتوى سوشيال (مجاني) → إعلان (200 ر.س) → واتساب → عرض سعر → بيع
```
